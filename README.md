# BAD BITCH BOD 🌿

An iPhone-friendly fitness tracker built with Expo / React Native Web.

## Features
- Home dashboard and weekly movement plan
- Beginner glute, lower-body, upper-body and full-body routines
- Workout completion and streak tracking
- Weight and optional waist logs
- Water tracker and nutrition journal
- Nintendo Switch activity minutes
- Local device storage
- Installable PWA support for iPhone Home Screen

## Deploy to GitHub Pages
1. Create a public GitHub repository named `bad-bitch-bod`.
2. Upload **the contents of this project folder** to the repository root (so `App.js`, `package.json`, `.github`, `public`, and `web` are at the top level).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **GitHub Actions**.
5. Open the **Actions** tab and wait for “Deploy BAD BITCH BOD to GitHub Pages” to finish successfully.
6. Your app URL will be `https://YOUR-GITHUB-USERNAME.github.io/bad-bitch-bod/`.

## Add to iPhone Home Screen
1. Open the published URL in Safari (not an in-app browser).
2. Tap the Share icon.
3. Choose **Add to Home Screen**.
4. Tap **Add**. Launch it from the new BAD BITCH BOD icon.

The app stores its logs locally in the browser on that device. Keep the same Home Screen app/browser data to retain your entries; clearing website data can erase them. This is a web app, not an App Store native iOS app.
